# 🎯 بوت جمعيا - Gameia Bot

## الأوامر المتاحة:
- `/start` - القائمة الرئيسية
- `/thismonth` - مين هيقبض الشهر ده
- `/gameia1` - جدول الجمعية الأولى كامل
- `/gameia2` - جدول الجمعية الثانية كامل

## رفع البوت على Railway (مجاناً):

1. روح على https://railway.app
2. سجل دخول بـ GitHub
3. اضغط "New Project" → "Deploy from GitHub repo"
4. ارفع الملفات على GitHub أو استخدم "Deploy from local"
5. البوت هيشتغل تلقائياً 24/7

## ملفات المشروع:
- `bot.py` - الكود الرئيسي
- `requirements.txt` - المكتبات
- `Procfile` - إعدادات التشغيل
